## 📝 Описание проекта
Интерактивное веб-приложение **«Доска публикаций»**, созданное для демонстрации навыков работы с асинхронным JavaScript, REST API и манипуляциями DOM. Проект объединяет знания о формах, событиях, `fetch`, `async/await`, JSON и HTTP-запросах. Приложение работает без перезагрузки страницы и не требует собственного бэкенда (используется бесплатный тестовый API).

## ⚙️ Реализованный функционал

1. **Загрузка публикаций (GET-запрос)**  
   - По нажатию кнопки выполняется запрос к `https://jsonplaceholder.typicode.com/posts?_limit=5`.
   - Осуществляется проверка успешности ответа (`response.ok`).
   - Данные парсятся из JSON и динамически выводятся на страницу через создание DOM-элементов (`document.createElement`).

2. **Создание публикации (POST-запрос)**  
   - Реализована строгая валидация: поля «Заголовок» и «Текст» не могут быть пустыми или состоять только из пробелов (`trim()`).
   - Используется `event.preventDefault()` для предотвращения стандартной перезагрузки формы.
   - Данные отправляются на сервер в формате JSON с заголовком `Content-Type: application/json`.
   - После успешного ответа (HTTP 201) выводится сообщение с ID и заголовком новой публикации, форма очищается, а новая карточка добавляется в начало списка.

3. **Обработка состояний и ошибок (UX/UI)**  
   - **Индикация загрузки:** во время выполнения запроса отображается сообщение со статусом `loading`, а соответствующая кнопка блокируется (`disabled`), чтобы предотвратить повторные нажатия.
   - **Обработка ошибок:** конструкция `try/catch/finally` перехватывает сетевые сбои и HTTP-ошибки (например, 404). Пользователю выводится понятное сообщение об ошибке, а кнопка разблокируется для повторной попытки.
   - **Цветовая схема сообщений:** желтый (загрузка), зеленый (успех), красный (ошибка).
